# Identitatea vizuală a aplicației

Aceste active reprezintă identitatea Clubului Suporterilor Cetatea Suceava. Emblema aplicației este originală și nu înlocuiește sigla oficială a echipei, păstrată separat în `public/echipe/cetatea-suceava.png`.

## Emblema

Fișier final: `cetatea-fan-emblem.png`

Versiune optimizată folosită de interfață: `cetatea-fan-emblem.webp`

Generată cu instrumentul integrat de generare de imagini, apoi procesată local pentru eliminarea fundalului cromatic. Fișierul final are canal alfa real.

Prompt:

> Emblemă originală pentru comunitatea suporterilor Cetatea Suceava: o cetate medievală monumentală ale cărei ziduri se transformă în tribunele unui stadion, două instalații discrete de nocturnă și trei siluete de suporteri în prim-plan, cu fular și steaguri. Stil de emblemă sportivă premium, vectorială, simetrică și lizibilă la dimensiuni mici. Paletă bleumarin, albastru regal, alb, cyan și auriu. Fără text, litere, cifre, mărci sau sigle existente.
